เว็บไซต์วิทยาลัยเทคนิคนางรอง (ขยายจากไฟล์ต้นฉบับที่ผู้ใช้ส่งมา)

วิธีใช้: แตก ZIP แล้วดับเบิลคลิก index.html หรือเปิดด้วย VS Code / Live Server
ไฟล์หลัก: index.html, about.html, service.html, detail.html, contact.html, building.html, location.html, department.html, facilities.html, gallery.html
ไฟล์ map.html ยังอยู่เพื่อรองรับลิงก์เดิม และใช้แผนผังเดียวกับ location.html
style.css: รวมดีไซน์เดิมและสไตล์ที่เพิ่ม
script.js: เมนูมือถือ, ค้นหา/กรองสถานที่ และดูภาพขนาดใหญ่
images/: ภาพที่มีอยู่ใน ZIP ต้นฉบับ (ไม่ดึงภาพจากที่อื่น)

ข้อควรทราบ: รายการสถานที่/สิ่งอำนวยความสะดวกบางส่วนเป็นตัวอย่าง ไม่ใช่ข้อมูลจริงที่ยืนยันแล้ว ตรวจสอบก่อนเผยแพร่
